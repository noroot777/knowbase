# Knowbase · 采集此页

用于把浏览器里已经打开的单篇文章正文补回现有 Knowbase 条目，不是自动浏览器爬虫。

## 安装与配对

1. 在本机 Knowbase 的订阅文章上点击「从浏览器补抓」。首次使用时下载并解压扩展。
2. 在 Chrome 的扩展管理页启用开发者模式，点击「加载已解压的扩展程序」，选择本目录。安装由用户自行操作。
3. 在 Knowbase 补抓页显示并复制本机配对密钥。在扩展中填写服务地址（默认 `http://127.0.0.1:8787`）与密钥，保存连接。只需配对一次。
4. 确认文章最终网址，发起采集请求。若原链接发生跳转，须在知识库里明确指定最终网址。同一篇、同一版本和网址会共用一个待办，改用其他最终网址时新请求替代旧请求；下拉项带有发起时间，可回补抓页取消本篇当前待办。
5. 在自己已经打开的文章标签点击扩展（或 Command+Shift+Y / Ctrl+Shift+Y）。选择对应条目，点击「读取此页」。识别不准时，在原文选好全文再用「读取所选文字」。
6. 核对标题、网址、正文完整性，勾选确认后点击「使用此正文」。这里只保存正文，不声称已经翻译或入库。回知识库选择等待同步，或明确启动该来源后续处理。

## 权限与边界

- `activeTab`：只有用户主动调用扩展，才读取当前文章标签。不枚举、扫描、导航、刷新、滚动或关闭其他标签。
- `scripting`：在隔离世界读取文章 DOM 或用户选中文字；清洗在克隆节点上进行，不改原页面。
- `storage`：在扩展本地保存服务地址和配对密钥，不使用同步存储。
- 回环地址 host 权限：只连接本机 Knowbase。Chrome 的 host 匹配无法限定端口，代码进一步限制为用户配置的本机 origin，并拒绝重定向。
- 不申请 Cookie、历史记录、全站读取权限；不上传整页 HTML、Cookie、表单、密码或浏览器登录凭据。首次配对时只与本机服务交换待办信息，正文必须经过预览确认才上传。
- 正文仅保存到用户绑定的原条目；网址须精确匹配（忽略片段），不信任网页自报的 canonical 地址。服务端版本比较防止覆盖已经变更或排除的条目。
- 使用已有的正文非重复字符门槛（400），最多 20 万字符，超限不偷偷截断。人工确认全文仍不可省略；DOM 提取无法证明全文加载完毕。
- 只允许知识库明确支持的 RSS、网页专栏和手动收录文章；简报摘要的外链指向第三方文章，不能用来替换摘要。暂不支持 PDF、浏览器内部页面、X 观点、时间线、跨域 iframe 和独立公众号采集器文档；登录后可见但尚未加载的全文不会被绕过。
- 待采集请求 15 分钟过期，服务重启会清除未完成请求。已保存正文和审计回执按文章持久恢复，关掉补抓页、另开标签、过期或重启后仍可查看并继续后续处理；退出重新采集不会丢失原回执。原条目更新、删除或排除后旧回执失效，页面定期核对。
- 最多同时等待 100 个采集请求；已保存、已取消或陈旧请求不占等待名额。
- ZIP 中的 `api.js` 与知识库补抓页共用错误解析；更新时请替换整个扩展文件夹并在扩展管理页重新加载，不要只复制 `popup.js`。
- 扩展未上传浏览器商店，需要用户手动安装；代码不会自动安装扩展或接管用户现有标签。
