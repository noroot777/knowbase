新建同步和重试失败项有什么区别？

新建同步：按本次通道、订阅和日期抓取。提取失败且仍在待处理列表中的文档，会在下次完整同步再次尝试；其他步骤仍受各自处理范围、去重和重试间隔限制。

重试失败项：抓取沿用上次的通道和范围，重跑失败阶段及必要的后续步骤；“正文为空”的提取问题在配了回填脚本时会先尝试回填。

凭证失效、模型配置或服务故障需先处理。重试不保证成功，也不代表强制重跑全部历史失败。

获取前，请确认本机操作

固定版本 wxkey 会请求 macOS 管理员授权、访问绿泡泡进程，可能退出或重启绿泡泡并创建重签名副本。请先保存正在编辑的消息。密码仅在系统授权框输入，页面不接收密码或明文 key；失败不会自动再次获取。

方式二：让你的智能体协助接入

复制提示词，交给在你的本机上、能访问本项目和终端的智能体。这里只复制说明，不会启动智能体或获取 key；获取前仍需你本人确认。

智能体处理完成后，回到这里点击「刷新状态」，确认已验证，再去同步公众号。

文章怎么获取？需要安装 skill 吗？

不需要安装个人情报库 skill。项目会准备独立 Reader，读取本机已同步的公众号推送，提取文章链接，再抓取公开正文、归档和索引；智能体用于后续分析。

仅覆盖本机已同步的推送，不保证订阅前的历史。私聊、群聊不会被作为文章采集。公众号正文图片走网页下载，不要求绿泡泡缓存图片解码 key。

本机推送是这里唯一的通道，正文按文章链接公开抓取，所以没有任何凭证要维护。另一条“逐号文章凭证”的通道（要 wxdown 抓包、要人去逐个点开文章）在 wechat-oa 分支上，主干不带它。绿泡泡接入支持 Mac 与 Windows x64 本机；Windows 获取仅适用于兼容的绿泡泡 4.x，确认后只读访问进程。远程服务器读不到你电脑上的绿泡泡。
