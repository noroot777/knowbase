# 我的收藏：从收藏夹到行动台

## 设计判断

这次不再围绕「如何清空待试清单」设计，而是围绕「想用的时候能找回，找到之后容易开始」。
假设使用者把工具、教程、文章和摘录都收进个人知识库；收藏不都意味着一项待办。
因此没有改成强制流转的看板，也没有增加需要手工维护的文件夹体系。

原页的主要障碍：

- 默认先看 AI 分诊，整理中的加载状态会挡住收藏；没有模型也容易让人无从下手。
- 内容分散在多段抽屉中，缺少收藏内搜索、来源筛选和统一排序。
- 命令、来源、处理按钮挤在每张卡片上；没有方便回忆「当时为什么收」的编辑入口。
- 「沉底」「多半不会再试」制造清单压力，删除和批量操作缺少充分保护。

## 新的信息架构

```text
我的收藏 · N 条                       发现好东西 / 整理设置
全部收藏 · 待探索 · 已完成 · 暂存

收藏架                                  灵感起步 / 当前收藏详情
┌────────────────────────────┐          ┌─────────────────────┐
│ 搜索标题、摘录、笔记、工具和命令 │          │ 一次只推荐一条，或者： │
│ 用途 / 用时快捷筛选             │          │ 摘录、来源、阅读入口   │
│ 来源、排序、卡片 / 紧凑、批量    │          │ 可复制的上手命令       │
│                            │          │ 我的随手记             │
│ 独立收藏卡片 · 一键打开阅读      │          │ 完成 / 暂存 / 删除     │
└────────────────────────────┘          └─────────────────────┘
```

- 默认是**全部收藏**，已完成和暂存的内容仍然能找回来。状态标签与用途筛选是两套独立维度。
- 每次收藏是一张独立卡；整篇与摘录保持各自的笔记、状态和定位信息，不悄悄合并。
- 搜索同时覆盖原文标题、行动卡名称与用途、摘要、账号、摘录、已保存笔记和命令。
- 用途筛选分成全部类型、十分钟以内、留点时间、灵感摘录、待整理；没有耗时信息不会编造分类。
- 选择一张卡片，在右栏就地预览和记笔记；卡片上的「打开阅读」仍可直接阅读，不强迫多点一次。
- 手机采用「收藏架 ↔ 详情」单栏切换，返回恢复卡片焦点；详情返回入口不被顶栏遮挡。
- `/`、`⌘/Ctrl K` 和手机顶栏搜索都搜索当前收藏；在手机详情内会先返回收藏架。

## 视觉选择

沿用全站瓷白 `#F3F5F4`、白卡 `#FFFFFF`、墨蓝黑 `#14202B`、深松绿 `#17604F`、浅松绿 `#F0F7F4`。
留时间的内容用紫色、摘录用琥珀色作辅助识别，不另造一套主题。
宋体用于收藏页标题与灵感起步，黑体承担阅读，等宽体承载命令和日期。
签名元素是卡片上的小书签和右侧的「随手记」，而不是大图或装饰性统计看板。
所有字体、图标与脚本本地可用，没有引入新框架或网络素材。

## 行为与保护

- AI 只给建议，后台整理不阻塞搜索或阅读。过期结果不再参与分类与批量建议。
- 保留重复项对比、「保留推荐，其余暂存」、重新考虑建议和按服务端阈值（默认 60 天）判断的暂存入口；批量建议执行前确认。
- 标为完成、暂存、放回待探索，以及批量状态变更可撤销上一次成功操作；不会删除原文或笔记。
- 批量请求逐条检查响应：失败项保持选中，成功项可以撤销，不会把 HTTP 错误当成成功。
- 删除先确认，仅删除这一条收藏与笔记，不删除原文章；删除不提供撤销，因此优先引导暂存。
- 笔记显式保存；切换收藏和刷新数据保留当前会话草稿，保存失败也保留；关闭或刷新页面时提醒未保存内容。
- 草稿没有跨浏览器会话持久化。搜索的是已保存笔记，而不是未保存草稿。
- 命令只复制，不自动执行；复制失败给出手工复制指引。未实际改动系统剪贴板，权限分支由状态测试覆盖。
- API 只新增 `GET /api/favorites?status=all`，旧的默认 `inbox` 与三个存储状态不变，无数据库迁移。

## 第 1 轮审查修复（2026-10-16）

完整读取本轮审查报告，接受并修复六项阻断意见，未扩展处理「不拦验收」的其他条目。

- **下拉框类问题**：收藏来源和排序、订阅来源过滤，以及公共禁用控件规则只覆盖 `background-color`，保留 base 的自绘箭头；收藏、订阅及窄屏图鉴控件均保留 28px 右侧空间。
  `tests/redesign_probe.mjs` 增加全站 `select` 普查，逐面板、窄屏检查所有已挂载下拉框（包括禁用状态），而非只列举收藏页两个 id。
- **选择保留类问题**：所有列表重绘共用 `pruneFavSelection`，只移除离开当前结果集的选中项。搜索、来源、用途筛选、排序、数据刷新与 AI 分类刷新不再各自维护不同口径；放宽筛选不会重新选中之前被剔除的条目。
- **AI 入口**：已完成、暂存和空列表也显示整理入口及运行/错误状态；重复、重新考虑和陈旧建议仍只指向当前加载的待探索收藏，并明确告知建议适用范围。
- **页头与空态**：页头只有同一行的「我的收藏」和总数，移除标语、副标题和页签旁的小字。空态只有左对齐说明和操作入口，不再渲染大图标或展示体标题。
- **色板**：收藏样式中的 35 处裸色值全部归并为现有共享 token；透明阴影由现有墨色 token 混合，不新增色板、不改 `:root`，也无需改变三个独立阅读/图谱产物。
- **陈旧口径**：前端消费响应的 `stale_days`，建议筛选、说明和确认弹窗共用该值；没有有效阈值时不猜测陈旧条目。继续使用可撤销的逐条状态更新，不改回不可逐项撤销的整库 `archive-stale`，保留后端旧接口兼容性。
