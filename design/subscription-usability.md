# 我的订阅：稳定外壳与阅读优先

2026-10-11 · ash task `LNbyVQEtCXth`

## 范围与依据

当前任务上下文没有附上两张原图，因此按仓库中「我的订阅」页的实际问题定位：
最新内容启用 `subs-reading`，管理及公众号却恢复普通页面的留白、字号和宽度。
实测从阅读切到管理，标题由 16px 变成 19px，页头由 y=0 移到 y=26。
阅读列表内部还重复放了来源操作、视图切换及状态说明，挤占列表高度。

本轮只调整订阅工作区，不改采集、翻译、索引、定时同步的业务逻辑，也不改变其他页面。
保留现有瓷白 `#F3F5F4`、白色 `#FFFFFF`、墨蓝黑 `#14202B`、松绿 `#17604F`
及边界 `#DCE3E0`；保留宋体页名、黑体正文和等宽计数，不另做一套视觉主题。

## 信息架构

```text
我的订阅 · 定时同步                 公众号 / 大V观点 / RSS / …
当前来源 · 收录统计 / 状态详情       最新内容 / 订阅管理 · 添加 / 同步
────────────────────────────────────────────────────────────
搜索 · 来源筛选                     正文与阅读工具
结果数量 · 清除筛选 / 只看列表       （管理时改为当前来源的同步设置）
可独立滚动的内容或订阅列表           可独立滚动的正文或设置
```

- `subs-mode` 管整页外壳，所有来源、阅读及管理共用相同页头和空间分配。
- 来源动作与视图切换移到全宽工具栏，不再重复占用列表列的高度。
- 桌面列表、正文和管理设置独立滚动；列表保持约四成宽度，阅读字号及完整正文不缩减。
- 管理列表使用同一个滚动容器，不再撑成数千像素的整页；同步设置有明确标题。
- 公众号同样占满可用工作区，连接及运行说明放进状态详情，仍保留可见的连接徽章。
- 状态详情是浮层，展开不挤压阅读区，支持点击外部和 Escape 收起。
- 内容搜索与管理搜索分别保存；返回阅读保留筛选、选中文章、两栏滚动位置及分页窗口。
  分页刷新沿用服务端单次最多 100 条的现有限制，本轮验证保留已加载的 60 条窗口。
- 筛选有「清除筛选」入口、匹配数量和可恢复的空态，不必手动删除关键词和来源选择。
- 来源标签支持方向键、Home、End 与单一 Tab 入口；列表支持方向键预览和 Enter 阅读。
- 手机来源标签只在自身横向滚动，不撑宽页面；手机管理纵向排列设置，保证保存入口可达。
  极矮窗口保留工作区最低高度，宁可允许整页滚动，也不裁掉列表和操作。

## 前后实测

使用相同隔离后端、相同样例数据和 1440×900 视口；原版静态资源直接取自起始提交。

| 指标 | 原版 | 本轮 |
| --- | ---: | ---: |
| 阅读列表开始位置 | 267.6px | 198.5px |
| 阅读列表可滚动高度 | 632.4px | 701.5px |
| 阅读 / 管理页头顶部 | 0 / 26px | 0 / 0px |
| 阅读 / 管理页头高度 | 53 / 37px | 53 / 53px |
| 阅读 / 管理标题字号 | 16 / 19px | 16 / 16px |
| 管理整页高度 | 7584px | 900px |

列表增加约 69px、约 11% 可读高度；管理与阅读的两层工具栏及列表起点保持一致。
1440×600 下列表高约 401.5px，可完整显示三条长观点；1440×1000 下可完整显示六条。
